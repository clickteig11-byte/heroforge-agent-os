# Deep Creative Research — Cross-Platform Design Intelligence

## Overview
Combines macro web architecture (Awwwards / Godly), tactile moodboard curation (Pinterest), mobile thumb-zone ergonomics (Mobbin), and modern browser standards (`modern-web-guidance`) into an actionable upgrade matrix for every site built in HeroForge V1.

## Triggers
- Before and during website implementation and refinement passes.
- When the user asks to research patterns to make sites better.

## Procedure

### Step 1: Four-Source Intelligence Matrix
For every website in progress, synthesize:
1. **Awwwards / Codrops (Spatial & Motion Engineering)**:
   - Continuous WebGL camera splines (`THREE.MathUtils.damp`), interactive exploded views, and SVG orthographic blueprint overlays.
2. **Pinterest (Materiality & Moodboard Curation)**:
   - Variable aspect-ratio editorial study grids (`4:5`, `16:10`, `1:1`) with extracted hex color tokens, focal length metadata, and tactile surface annotations.
3. **Mobbin (Mobile Ergonomics & Flow Patterns)**:
   - Floating bottom thumb-zone action bars on mobile (`390px`), segmented pill switchers, and native top-layer `<dialog>` sheets.
4. **Godly / Swiss Monographs (Typographic & Grid Tension)**:
   - Exposed `1px` architectural hairlines, tabular monospace telemetry (`font-variant-numeric: tabular-nums`), and high-contrast serif/grotesk pairings.

### Step 2: Direct Code Injection Contract
Research must never remain theoretical. Every research insight must map to a concrete UI component in the active build (e.g., `<EditorialPinBoard />`, `<MobileThumbDock />`, `<BlueprintComparator />`).

## Expected Outputs
- Research-backed interactive components in Website A, Website B, and the HeroForge Agent OS Dashboard.

## Verification Criteria
- [ ] Research insights from all 4 sources are visibly implemented in the live rendered websites.

## Minimalist Hero Restraint Law (A+ Showcase Standard)
- **Strict Element Cap**: Keep only 1 floating navigation bar, 1 small unboxed project label, 1 intentional 2-line headline, 1 short sentence (`<= 38ch`), 1 primary CTA button, and at most 1 subtle supporting caption/switcher.
- **No Decorative Jargon**: Use clear human navigation words (`Projects`, `Studio`, `Movement`, `Craft`, `Inquire`) — never templated AI labels.
- **Intentional Line Wrapping**: Balance headline lines explicitly so a short word is never stranded alone on its own line.
- **Subject Dominance & Color Boundary**: Keep `>= 65%` of the hero image/3D subject unobstructed, and keep workspace accent colors (`#58A6FF` light blue) strictly inside the Agent OS dashboard.
