# Composition Brief — HeroForge V1 (60-Second X-Post Motion-Graphics Video)

- **Canvas**: `1920px × 1080px`
- **Deterministic Clock**: `window.__setRenderTime(seconds)` (`0.0` to `60.0`)
- **Typography**: `Cormorant Garamond` / `Instrument Serif` (Display), `Plus Jakarta Sans` (UI), `JetBrains Mono` (Telemetry)
- **Color Architecture**:
  - Agent OS scenes use Chalkboard Slate (`#121417`) + Mineral Light Blue (`#58A6FF`).
  - Flagship Website scenes strictly isolate brand palettes (Warm Museum Ivory `#FCFAF6`, Champagne Brass `#C5A478`, Volcanic Basalt `#161514`, Tungsten Amber `#E09F5A`, Pressed Amber `#C98A54`, Vermilion `#D95338`, Optical Gold `#C8A26A`).
